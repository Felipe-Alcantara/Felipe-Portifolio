## 📋 Sobre o Projeto

Repositório com os projetos práticos desenvolvidos durante o curso de **desenvolvimento web** do **MDN Web Docs** (Mozilla Developer Network). Cada projeto acompanha uma etapa do aprendizado, do HTML básico até conceitos mais avançados.

## 📁 Estrutura do Projeto

```
MDN-Web-Docs/
│
├── 📁 projetos-web/           # Projetos do curso
│   └── 📁 site-teste/         # Primeiro projeto — página HTML básica
│       ├── 📁 Imagens/        # Imagens do projeto
│       ├── index.html
│       └── Planejamento.txt

└── LICENSE
```

## 🎯 Como Usar

### Opção 1: Acesso direto (Recomendado!) 🌐

**🚀 Link direto:** [mdn-web-docs.felixo.com.br](http://mdn-web-docs.felixo.com.br)

### Opção 2: Rodar localmente

```bash
# Clone o repositório
git clone https://github.com/Felipe-Alcantara/MDN-Web-Docs.git

# Entre na pasta
cd MDN-Web-Docs

# Abra o index no navegador
xdg-open index.html
```
