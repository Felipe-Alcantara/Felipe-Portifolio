## Descrição do Projeto
Este repositório agrupa quatro aplicações de estudo em C#:
- calculaSalario: console app que faz um cálculo simples de salário
- ConceitosBasicos: demonstrações iniciais de variáveis, constantes e leitura de dados
- ControleContas: implementação de classes Cliente e Conta com operações de depósito, saque e transferência
- TestControleContas: projeto de testes MSTest para validar funcionalidades de Conta

## Estrutura de Pastas
- calculaSalario/: solução de cálculo de salário
- ConceitosBasicos/: exemplos básicos de console
- ControleContas/: lógica de negócio de contas bancárias
- TestControleContas/: testes unitários MSTest

## Funcionalidades Implementadas
- Estrutura básica de classes Cliente e Conta
- Métodos de depósito, saque e transferência em Conta
- Exemplo de cálculo de salário e de fluxo de console

## Limitações e Problemas
- Testes não executam corretamente devido a erros de configuração e Assert
- Funções adicionais (ex.: saque especial, limites, validações extras) não foram implementadas
- Alguns cenários de exceção (CPF inválido, idade mínima) estão sem cobertura de teste
