## 📋 Sobre o Projeto

Este repositório reúne exercícios do livro **Introdução à Programação com Python**, desenvolvidos na disciplina de **Programação I**.  
A estrutura foi reorganizada para facilitar navegação, manutenção e evolução do conteúdo com padrão de qualidade inspirado no **Felixo Standards**.

---

## 📁 Estrutura do Projeto

```text
Trabalho-da-faculdade/
│
├── 📁 src/                                    # Código-fonte do projeto
│   ├── 📁 exercicios/                         # Exercícios separados por disciplina/módulo
│   │   └── 📁 programacao_i/                  # Exercícios de Programação I
```

## 🧰 Ferramentas / Conteúdo Disponível

### 🧮 Exercícios de Programação I (`src/exercicios/programacao_i/`)

**Arquivos incluídos por capítulo:**
- `capitulo_3/`: exercícios `3.7` até `3.15`
- `capitulo_4/`: exercícios `4.3` e `4.4`
- `capitulo_5/`: exercício `5.11`

📖 [Ver guia dos exercícios](src/exercicios/programacao_i/README.md)

---

### 👥 Projeto Integrado da Equipe (`src/projetos/trabalho_integrado/`)

**`trabalho_programacao_i_equipe.py`**
- Consolida múltiplos exercícios em um único arquivo
- Mantém identificação dos integrantes da equipe no código
- Pode ser usado como versão completa da entrega acadêmica

📖 [Ver guia do projeto integrado](src/projetos/trabalho_integrado/README.md)

## 🚀 Como Usar

### Opção 1: Executar um exercício específico (Recomendado)

```bash
# Execute um exercício isolado (exemplo: capítulo 3, exercício 3.7)
python3 src/exercicios/programacao_i/capitulo_3/exercicio_3_7_soma_dois_inteiros.py
```

### Opção 2: Executar o trabalho integrado da equipe

```bash
# Roda o arquivo consolidado com múltiplos exercícios
python3 src/projetos/trabalho_integrado/trabalho_programacao_i_equipe.py
```

---

## 📚 Guia Rápido

### Para iniciantes
1. Abra a pasta `src/exercicios/programacao_i/`.
2. Escolha um exercício pelo capítulo.
3. Execute com `python3 caminho/do/arquivo.py`.

### Para revisão acadêmica
1. Use os arquivos separados por capítulo para correção individual.
2. Use `trabalho_programacao_i_equipe.py` para visão consolidada da entrega.

## 🔧 Funcionalidades Técnicas

- **Conversões e cálculos básicos**: soma, conversão de unidades, tempo em segundos.
- **Regras condicionais**: maior/menor número e reajuste salarial por faixa.
- **Simulações simples**: custo de viagem, aluguel de carro e rendimento de poupança.

---

## ⚠️ Limitações

- Scripts são interativos e dependem de entrada manual no terminal.
- Não há suíte de testes automatizados neste repositório.
- Os exercícios foram mantidos próximos ao formato original acadêmico.
