## 📋 Sobre o Projeto

Este repositório centraliza meus exercícios de **lógica de programação** e **fundamentos de Python** feitos durante o curso. O objetivo é manter uma trilha prática por módulo, com foco em evolução progressiva e revisão rápida.

Os arquivos estão separados por pasta (`Módulo 001` até `Módulo 011`) para facilitar estudo, execução local e manutenção do histórico de aprendizado.

## 🚀 Ferramentas Disponíveis

### 🧠 Exercícios de Lógica e Fundamentos (`Exercícios/`)

**`Ex001 - Guardando informações...py`**
- Entrada de dados básicos do usuário
- Uso inicial de variáveis e impressão formatada
- Exemplo: `nome + idade + peso` → saída organizada com borda

**`Ex003 (Teste If e else...) somando números...py`**
- Soma de números com validações simples
- Introdução ao uso de **if/else**
- Exemplo: `n1 + n2` → resultado exibido no terminal

**`Ex004 (...Dissecando uma Variável).py`**
- Verificação de tipo e propriedades de entrada
- Uso prático de identificadores de string
- Exemplo: `"123"` → checagens como `isnumeric`, `isalpha`, etc.

**`Ex005 e 006 (...Antecessor e Sucessor...).py`**
- Cálculos derivados de um número informado
- Operações de antecessor, sucessor, dobro, triplo e raiz
- Exemplo: `n` → `n-1`, `n+1`, `2n`, `3n`, `√n`

**`Ex007 (Cálculo de média...).py`**
- Cálculo de média aritmética de notas
- Aplicação de operadores matemáticos básicos
- Exemplo: `nota1 + nota2` → `média final`

**`Ex008 (conversores).py`**
- Conversão de unidades de distância e peso
- Prática com escala de unidades
- Exemplo: `metros` → `cm` e `mm`

**`Ex009 (Tabuada).py`**
- Geração de tabuada de um número
- Estrutura de repetição aplicada a cálculos
- Exemplo: `7` → tabuada do `7`

**`Ex010 (conversor de dolar).py`**
- Conversão de moeda com base em cotação
- Operações de divisão e formatação numérica
- Exemplo: `R$ valor` → `US$ equivalente`

**`Ex11 (Calcular tinta necessária).py`**
- Estimativa de tinta com base na área
- Exercício de aplicação prática com regra de negócio
- Exemplo: `área da parede` → `litros de tinta`

## 🚀 Como Usar

### Opção 1: Execução direta de um exercício (Recomendado)

```bash
# Execute um arquivo Python específico
python "Exercícios/Módulo 009/Ex009 (Tabuada).py"
```

### Opção 2: Clonar o repositório completo

```bash
# Clone o projeto
git clone https://github.com/Felipe-Alcantara/Curso-em-video.git

# Entre na pasta
cd Curso-em-video

# Execute qualquer exercício
python "Exercícios/Módulo 001/Ex001 - Guardando informações (Nome, idade, peso) + def de borda (Finalizado).py"
```

## 📚 Guia Rápido

### Para Iniciantes
1. Escolha um módulo em `Exercícios/`.
2. Rode o arquivo `.py` no terminal.
3. Leia o enunciado no nome do arquivo e compare com a saída.

### Para Revisão Técnica
1. Navegue por módulo para ver progressão de dificuldade.
2. Refaça os exercícios sem olhar o código.
3. Compare sua solução com a versão do repositório.
