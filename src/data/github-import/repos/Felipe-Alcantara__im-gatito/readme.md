# Im gatito 💖

Um site fofo e rosa dedicado ao meu gatinho dançando com música especial! Criado com muito amor para celebrar momentos felizes.

## ✨ Funcionalidades

- **Gatinho dançando**: GIF animado com efeito neon pulsante.
- **Música de fundo**: Música especial tocando automaticamente em looping.
- **Controle de volume**: Slider rosa para ajustar o volume da música.
- **Corações flutuantes**: Animação de corações subindo pela tela para um toque ainda mais encantador.
- **Design rosa e coquete**: Tema totalmente rosa com gradientes suaves e efeitos visuais.

## 🚀 Como Usar

1. **Clone ou baixe o repositório**:
   ```bash
   git clone https://github.com/seu-usuario/im-gatito.git
   cd im-gatito
   ```

2. **Inicie um servidor local** (recomendado para carregar arquivos de mídia):
   - Com Python (se instalado):
     ```bash
     python -m http.server 8000
     ```
   - Ou use qualquer servidor web local (como Live Server no VS Code).

3. **Abra no navegador**:
   - Acesse `http://localhost:8000` (ou a porta do seu servidor).
   - A música começará automaticamente (ou após o primeiro clique, dependendo do navegador).
   - Ajuste o volume com o slider se desejar.

## 🛠️ Tecnologias Usadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilos, animações e efeitos visuais (gradientes, box-shadow, keyframes).
- **JavaScript**: Interatividade (corações flutuantes, controle de áudio).
- **Python HTTP Server**: Para servir localmente (opcional).

## 🎵 Música e Imagens

- **Música**: Arquivo MP3 personalizado (substitua por sua música favorita).
- **GIF**: Imagem animada do gatinho (pode ser trocada por outro GIF).

Para personalizar:
- Substitua `musica.mp3` por seu arquivo de áudio.
- Troque `c57f58245f7799f6c39f7f8c9b7149d2.gif` por outro GIF (mantenha o nome ou atualize o `src` no HTML).

## 🌟 Personalizações Sugeridas

- **Mudar cores**: Edite as variáveis de cor em `styles.css` (ex.: `rgba(255,105,180,...)` para tons de rosa).
- **Mais animações**: Adicione keyframes no CSS para novos efeitos.
- **Interatividade**: Expanda o JS para mais controles (ex.: botão pause/play).
