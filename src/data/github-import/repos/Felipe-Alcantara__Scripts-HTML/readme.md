## 📋 Sobre o Projeto

Repositório de estudos com projetos práticos de **HTML5** e **CSS3**. O foco é aprender a estrutura de páginas web e a estilização de componentes reais, como formulários de cadastro.

## 📁 Estrutura do Projeto

```
Scripts-HTML/
│
├── 📁 docs/                          # GitHub Pages (demo online)
│   ├── index.html                    # Formulário de Cadastro
│   ├── Formulário.CSS                # Estilos do formulário
│   └── CNAME                        # Domínio customizado
│
├── 📁 FORMULÁRIO COM HTML e CSS!/    # Versão local do formulário
│   ├── Brython.html                  # Página principal
│   └── Formulário.CSS                # Estilos
│
├── README.md                         # Este arquivo
└── LICENSE
```

## 🚀 Projetos Disponíveis

### 📋 Formulário de Cadastro (`docs/` e `FORMULÁRIO COM HTML e CSS!/`)

**`index.html`** / **`Brython.html`**
- Formulário completo de cadastro de desenvolvedor
- Campos de texto para nome, sobrenome e e-mail
- Seleção de área de atuação: `Front-end` → `Back-end` → `Fullstack`
- Dropdown de senioridade: Junior, Pleno, Sênior
- Checkboxes de linguagens: HTML, CSS, JavaScript, PHP, C#, Python, Java
- Área de texto para descrição de experiência

## 🎯 Como Usar

### Opção 1: Demo Online (Recomendado!) 🌐

**🚀 Link direto:** [scripts-html.felixo.com.br](https://scripts-html.felixo.com.br)

### Opção 2: Localmente

#### Instalação

```bash
# Clone o repositório
git clone https://github.com/Felipe-Alcantara/Scripts-HTML.git

# Entre na pasta
cd Scripts-HTML
```

#### Executando

Abra o arquivo diretamente no navegador:

```bash
# Linux/Mac
xdg-open "FORMULÁRIO COM HTML e CSS!/Brython.html"
```

Ou simplesmente arraste o arquivo `Brython.html` para o navegador.
