# Projeto HTML

> Projetos semânticos e estruturados com HTML5

## 📝 Sobre

Coleção de projetos focados em HTML semântico, acessibilidade e boas práticas de estruturação web.

## ✨ Funcionalidades

- **HTML5 semântico** com tags apropriadas
- **Acessibilidade** (ARIA, alt texts)
- **SEO otimizado** com meta tags
- **Estrutura limpa** e organizada
- **Validação W3C** completa

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)

## 📦 Estrutura

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Projeto HTML</title>
</head>
<body>
  <header>
    <nav><!-- Navegação --></nav>
  </header>
  <main>
    <section><!-- Conteúdo principal --></section>
  </main>
  <footer><!-- Rodapé --></footer>
</body>
</html>
```

## 🎯 Boas Práticas

- Uso correto de tags semânticas
- Hierarquia de headings (h1-h6)
- Atributos alt em imagens
- Labels em formulários
- Meta tags para SEO
