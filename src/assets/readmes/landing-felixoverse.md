# Landing FelixoVerse

> Uma landing page moderna e interativa para o universo FelixoVerse

## 🚀 Sobre o Projeto

Este projeto é uma landing page desenvolvida com React e Tailwind CSS, apresentando uma interface moderna com animações fluidas e design responsivo. A página serve como porta de entrada para o ecossistema FelixoVerse.

## ✨ Funcionalidades

- **Hero Section** com animações de entrada
- **Navbar responsiva** com navegação suave
- **Carrossel contínuo** de projetos
- **Design moderno** com gradientes e efeitos visuais
- **Totalmente responsivo** para todos os dispositivos

## 🛠️ Tecnologias Utilizadas

- React 18
- Tailwind CSS
- Framer Motion
- Vite
- Lucide React (ícones)

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/felixo/landing-felixoverse.git

# Entre na pasta do projeto
cd landing-felixoverse

# Instale as dependências
npm install

# Execute o projeto
npm run dev
```
