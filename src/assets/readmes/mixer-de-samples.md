# Mixer de Samples

> Ferramenta web para combinar e mixar loops de áudio em tempo real

## 🎵 Sobre o Projeto

Um mixer de samples desenvolvido para o navegador, permitindo que usuários combinem diferentes loops de áudio, ajustem volumes e criem suas próprias mixagens musicais.

## ✨ Funcionalidades

- **Player de múltiplas faixas** simultâneas
- **Controle de volume** individual por faixa
- **Sincronização de BPM** automática
- **Efeitos de áudio** em tempo real
- **Exportação** de mixagens
- **Biblioteca de samples** integrada

## 🛠️ Tecnologias Utilizadas

- React 18
- Web Audio API
- Tailwind CSS
- Framer Motion
- Tone.js

## 🎮 Como Usar

1. Carregue seus samples de áudio
2. Ajuste o BPM base
3. Combine diferentes loops
4. Aplique efeitos
5. Exporte sua mixagem

## 📦 Instalação

```bash
npm install
npm run dev
```
