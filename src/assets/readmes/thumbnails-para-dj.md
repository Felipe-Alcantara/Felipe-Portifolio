# Thumbnails para DJ

> Presets de capas para sets de música no estilo neon/pastel

## 🎨 Sobre o Projeto

Uma coleção de templates e presets para criação de thumbnails de sets de DJ, com foco em estilos neon e pastel. Inclui ferramenta web para personalização rápida.

## ✨ Funcionalidades

- **50+ templates** pré-definidos
- **Editor visual** integrado
- **Paleta de cores** neon/pastel
- **Tipografia** especializada para música
- **Exportação** em alta resolução
- **Formatos múltiplos** (YouTube, Instagram, SoundCloud)

## 🛠️ Tecnologias Utilizadas

- React 18
- Canvas API
- Tailwind CSS
- Fabric.js
- Color.js
- FileSaver.js

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/felixo/dj-thumbnails.git

# Instale as dependências
npm install

# Execute o editor
npm run dev
```

## 🎮 Como Usar

1. Escolha um template base
2. Adicione o título do seu set
3. Selecione a paleta de cores
4. Ajuste tipografia e efeitos
5. Exporte em alta resolução

## 📐 Formatos Suportados

- **YouTube**: 1280x720px
- **Instagram**: 1080x1080px
- **SoundCloud**: 800x800px
- **Spotify**: 640x640px
